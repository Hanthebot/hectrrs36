# Hectrrs36
sub 100x100 mm 36 key split keyboard with splay - and TRRS jack!

## Specs
Minor derivated work of ezxzeng's [Hector36 keyboard](https://github.com/ezxzeng/hector36), now with RP2040 zero and TRRS!

## Build guide
WIP, but it should be straightforward.
Maybe checkout uploaded images. 

BOM:
- 2 x PCB (reversible)
- 2 x TRRS socket (PJ320A)
- 2 x RP2040 Zero (no pins required, SMD)
- 36 x MX hotswap socket or variants

In case you are going sandwich cases like me:
- 10 x M2 bolt (length 6 mm)
- 10 x M2 nut (diameter 3 mm)
- 10 x M2 standoff (height 7mm - flexible)
- maybe 8-10 bumpons

Tips:
1. Jump at the back
2. Use 90 degree TRRS jack, and 90 degree usb c cable if possible
    -  due to weird locations of TRRS. It may be fixed in the future

With these being said, it could be the most accessible way to try a splayed keyboard / totem layout!
